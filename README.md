##  How It Works

1. **Upload** — User uploads a PDF or study document ----- (English Language Supported)
2. **RAG Pipeline** — Document is chunked, embedded, and stored in a vector store
3. **Query** — User sets quiz preferences (difficulty, count, topic)
4. **Generation** — LLaMA 3.3 70B retrieves relevant chunks and generates MCQs
5. **Quiz** — User solves the quiz at their own pace
6. **Results** — Score is saved and reflected in the Performance Dashboard
